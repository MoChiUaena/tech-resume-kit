# v0.11.1 发布验收记录

本维护版集中修复 PDF 导出与编辑模式切换的保存一致性。完整 Markdown 改名后下载使用新姓名；PDF 固定当前简历和版本，等待完整文件再下载；冲突保留页面输入并恢复操作。

## 用户流程与安装

Windows 包通过真实启动程序与包内 Node、Chromium 执行，移除系统 Node 的 PATH，禁止外部请求并使用失效网络代理。十步流程覆盖首次启动、起步选择、字段错误定位、填写与图片、PDF 下载、外部修改冲突、关闭程序后的草稿恢复、单份和整库恢复、小屏填写与再次启动。

源码 TGZ 在仓库外安装并验证 CLI、ESM 接口、TypeScript、三种起步内容和实际 PDF；Starter ZIP 通过安装、导出和本地预览入口验证。Windows、macOS Intel / Apple Silicon、Linux x64 / ARM64 的候选包由同一候选提交在相应 CI 环境构建和启动，最终结果随正式包记录。

本地验证中，新版首次读取前后 37 个原始文件逐项一致；编辑后另外 26 个原文件保持不变。三份在用简历、一份回收站资料、当前选择、图片与历史均保留；单份和整库恢复、旧程序重新打开、新版再次启动通过。后续 CI 采用各自实际计数，不固定资料文件数量。

用户流程的三份 PDF 各一页；升级的三份 PDF 分别为一页、两页、两页，共八页。检查文字、字体嵌入、链接、两张独立图片和页面边界，并用 Poppler 逐页渲染查看。奶龙姓名、23:31 头像、右上学校 Logo 和墨蓝主风格保持正常。

升级测试主动添加合成内容触发第二页，末页较空用于验证分页与重启，不作为公开样张。正式候选包以相同的检查和逐页渲染结果作为发布门槛；具体报告绑定实际 ZIP 的 SHA-256。

## 正式发布依据

版本号与锁文件统一为 `0.11.1`。发布标题为 `v0.11.1 - 导出与编辑稳定性修复`；tag 对应通过六项 CI 的准确候选提交。实际测试数量、提交、CI、各平台启动和 Windows 升级 / 用户流程结果见随包 `release-validation.json`，全部公开文件摘要见 `SHA256SUMS.txt`。

旧版正式文件和 v0.11.0 历史验收保持不变。将新包解压到新的程序目录，继续选择原数据目录即可使用。
