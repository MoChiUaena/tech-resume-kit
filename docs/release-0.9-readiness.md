# v0.9.0 验收范围

v0.9.0 包括起步模板选择与填写导航、常用内容表单、macOS 双击应用，以及工作台模型转换接口。工作台自身的界面接线在另一个项目完成，本套件交付转换 API、命令与差异报告。

## 升级验收

本地使用 GitHub 正式发布的 v0.8.0 Windows ZIP，SHA-256 同时与 GitHub 摘要和公开校验文件一致。启动当前开发包前后，36 个原始数据文件逐项核对一致；数据位置与设置文件也保持一致。

验证资料含三份在用简历、一份回收站资料、独立图片和手动历史。已验证旧资料直接进入编辑器、通过新表单修改技能与补充章节、单份恢复、整库恢复及撤销、旧程序重新打开和新版再次启动。编辑当前简历后，另外 25 个原文件保持不变。

实际导出的三份 PDF 为一页、两页、两页，共五页，均核对文字、图片、字体、链接与页边界，并渲染逐页查看。两页输出保持原字号；奶龙头像与右上角校徽继续使用独立槽位。

升级报告保存在 `tmp/packages/upgrade-smoke.json`，PDF 与截图在 `tmp/pdfs/upgrade/`；CI 以相同的正式基线运行完整验收，并上传验证产物。发布组装要求报告中的基线和候选摘要匹配，不固定某次测试的文件数量。

## 集中发布前

正式版本 `0.9.0` 以六项成功 CI 的准确提交、下载包和报告组装草稿。macOS Intel / Apple Silicon `.app` 与现有跨平台启动包一并收录；确认全部归档版本、运行组件摘要和下载清单一致后，再公开发布。

正式标题采用 `v0.9.0 - 表单填写与首次使用优化`。v0.8.0 的公开文件继续保留。
