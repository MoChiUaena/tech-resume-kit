# v0.12.0 发布验收记录

本版本集中提供六套独立外观、十种起步内容与完整 PDF 预览。外观和内容独立组合，保留墨蓝样张、奶龙姓名、23:31 头像及独立学校 Logo。

## 完整预览与资料保护

完整预览使用随包的匿名一页 PDF，在离线查看器中显示可选文字、链接与缩放。打开、关闭或预览另一种外观不创建简历，也不改变当前资料或已选外观；点击“使用此风格”才更新创建时的选择。关闭后焦点返回原按钮。

桌面和窄屏验证覆盖六套预览、125% 缩放、适合宽度、Escape 返回、两个创建入口及原资料不变。未知文件、外部来源和非预期查询参数在请求 PDF 前拒绝。空白内容采用中性岗位、学历与日期填写提示。

发布前完整 Node.js 回归为 183 项全部通过，包含 iframe 内聚焦预览页面和缩放控件后按 Escape 的检查。关闭完整预览后保留创建对话框和输入，焦点回到预览按钮。

## PDF 与边界

六套外观的一页和两页样张继续复核完整文字、嵌入字体、链接、图片和页边界。边界案例按外观覆盖仅照片、仅校徽、无图片、长姓名与链接、自定义章节标题和字号/页边距设置；超限内容明确拒绝，正文不自动缩小。页尾标题必须跟随首段。

PDF 验收采用实际导出文件与逐页渲染；准确候选的具体案例、页数与检查结果随 CI 产物保存，最终测试数量写入随包 release-validation.json。

发布前边界矩阵共执行 59 个案例：45 份 PDF、51 页通过文字、字体、链接、图片、页边界与标题跟随检查并逐页复核；14 个超限案例按预期拒绝。Graphite 的两份长内容夹具允许第二页较疏，检查给出提示；它们用于边界验收，不作为公开样张。

## 安装、升级与正式发布

源码 TGZ 和 Starter ZIP 在仓库外安装，验证 CLI、ESM、TypeScript、十种内容、六套外观及完整预览文件。各平台运行组件和模板随包提供。

升级基线为正式 v0.11.1 Windows ZIP，SHA-256 为 `7a12294f999682db6209aaaf5651df6554cf435d08d477d288cfd1475a13016b`。升级流程核对原资料、图片、历史、当前选择与回收站，验证备份恢复、旧程序重新打开和新版重启。已有新主题资料如需用 v0.11.1 或更早程序打开，应先在新版切回墨蓝。

发布前 Windows 升级演练核对 37 份原文件，覆盖三个简历、回收站、表单修改、章节设置、单份与整库备份恢复，以及离线预览和重启保留。正式发布使用准确候选 CI 重建的包，并将升级与用户旅程记录中的包摘要与实际下载文件逐一匹配。

正式标题为 `v0.12.0 - 外观模板与完整预览`。tag 绑定通过六项 CI 的准确候选提交，资产摘要与实际验收依据见 SHA256SUMS.txt 和 release-validation.json。旧版公开文件保持原样；将新程序解压到新的程序目录，继续选择原数据目录即可升级。
