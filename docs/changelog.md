# 变更记录

## 0.9.0-dev.4 - 开发中

- 新数据目录提供起步模板选择，可从空白填写、奶龙校招或两页工作经验开始，也可直接填写。
- 填写导航可展开基本信息、经历、技能与补充信息，或打开版式与图片设置。
- 已有、迁入或从备份恢复的资料直接进入编辑；起步入口可新建独立简历，保留当前正文、图片与历史。
- 引导状态单独保存在数据目录，关闭或选择后重启不再重复显示；旧窗口和外部修改仍检查版本冲突。
- 升级验收改为实际发布的 v0.8.0 包，覆盖新表单、多简历、回收站、备份恢复、旧程序重新打开和新版重启。
- 发布组装核对实际升级报告与候选摘要，同时收录两个芯片的 macOS 原生应用包及启动验证。

此版本尚未发布 Release，公开下载仍为 v0.8.0。

## 0.9.0-dev.3 - 开发中

- 新增技能与补充信息表单，技能支持编辑、复制、排序与删除，补充章节可新增、编辑和删除。
- 新增工作经历入口，常用内容均可通过表单填写；Markdown、加粗、链接与段落顺序保持兼容。
- 删除前完整备份，恢复保留图片与内容；旧窗口、简历切换和外部修改不会被覆盖。
- 一页超量时可直接选择允许两页，或打开版式设置，字号保持原设置。

此版本尚未发布 Release，公开下载仍为 v0.8.0。

## 0.9.0-dev.2 - 开发中

- 新增 macOS Intel / Apple Silicon 原生 `.app`，内置运行组件，支持双击打开、再次打开、退出与独立数据目录。
- 新增应用资源完整性检查与篡改检测，保存与重启不改动包内程序资源；无需配置证书或开发者账号。
- 草稿主题与说明显式填写，测试数量来自实际 CI 报告，避免沿用旧版发布数据。

开发产物由 GitHub CI 提供，公开下载仍为 v0.8.0。

## 0.9.0-dev.1 - 开发中

- 新增工作台模型版本 2、3、4 的显式转换 API 和 JSON 命令，保留章节顺序、段落、列表、加粗、原 ID 映射与完整元信息。
- 目标版式、图片映射和分页差异必须明确处理，输出转换报告；未知字段、未合成的裁剪效果和错误素材 ID 会定位到具体字段。
- 转换输出保护原文件与选项，重新计算图片相对路径；失败时保留已有输出。
- 结构化条目可省略日期，Markdown 原规则保持兼容；新增双图、无图和两页转换 PDF 验证。

此版本尚未发布 Release，公开下载仍为 v0.8.0。

## v0.8.0 - 简历管理与跨平台启动

- 已有教育、实习、工作与自定义经历可编辑、复制、上下移动和删除，保留段落、编号列表、加粗与链接。
- 删除经历前保存完整备份，移除最后一条时同步处理空章节与排序；旧窗口或外部修改不会被覆盖。
- 简历回收站保留正文、图片和历史，恢复时可更名，至少保留一份在用简历。
- 整库 ZIP 包含全部简历、回收站、图片、历史和当前选择；恢复前保留原库 ZIP，失败或中断可回退。
- macOS Intel / Apple Silicon、Linux x64 / ARM64 启动包内置 Node、Chromium、字体和依赖，提供组件与环境检查。
- 设置界面按平台显示文件夹操作；现有数据位置与内容模型继续兼容。
- 使用已发布的 v0.7.0 包验证升级，逐文件核对原资料，并检查旧程序重新打开、回收站与重启保留。

macOS 包尚未签名、公证，Windows EXE 尚未签名；Linux 系统依赖与启动方式见[跨平台说明](portable.md)。

## v0.7.0 - 简历编辑与数据管理

- 照片裁剪支持拖动、缩放、旋转和重置，保存为 23:31 竖版 JPEG；调整已有照片前保留历史备份。
- 教育、实习与项目经历可通过表单添加，自动生成 Markdown 条目和日期字段，并合并到对应章节。
- 新增章节时同步已有排序配置；旧正文和其他简历保持不变。
- 数据与程序分开保存，支持查看、更换位置和打开已有简历库；旧版 `my-resume` 可自动识别或手动迁入。
- 迁移前保留整库副本，逐文件核对大小与 SHA-256；原资料、所有简历、图片与历史保留。
- 正式版本检查、安装包下载与 SHA-256 核验、独立目录准备、保存后切换及启动失败回退。
- 更新下载支持暂停、断线续传和重启后继续；准备完成的新版保存在本机，切换前重新核对程序文件。
- 小窗口中的“数据与更新”弹窗固定标题与关闭按钮，并显示下载进度和继续下载入口。
- 编辑器与命令行预览使用随包提供的离线 PDF 预览器，支持翻页、缩放、文本选择和正文链接；解决内置浏览器的原生 PDF 预览黑屏。

从 v0.6.0 升级时，首次启动会识别旧版 `my-resume`，迁移前保留整库副本。其他位置的资料可以通过“数据与更新 → 迁入旧版 my-resume”选择。版本发布规则见[维护说明](maintaining.md)。
