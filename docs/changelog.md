# 变更记录

## 0.11.0-dev.2 - 开发中

- 主编辑区的未保存输入按简历和窗口独立暂存，刷新或程序重启后提供恢复、稍后及删除入口；草稿文件与正式资料分开。
- 恢复继续检查原文件版本，保存响应只清理对应输入；切换简历立即清除旧恢复选项，损坏记录保留并提示，不影响正常编辑。
- 浏览器缓存支持当前页面地址下的即时刷新恢复；复制数据目录带上草稿，单份和整库 ZIP 继续只导出简历资料。

## 0.11.0-dev.1 - 开发中

- 保存失败时可下载当前页面的未保存草稿 ZIP，包含正文、版式和可读取图片，复用“备份与恢复”导入。
- 草稿导出保留未完成的完整 Markdown、BOM / CRLF 以及未修改的元数据注释；导出按页面快照生成，不覆盖已保存资料。
- 备份中的合法相对图片路径统一转换并保持可恢复；导出与恢复均提前校验路径转换后的正文大小，超限恢复在写入图片前停止。

## 0.10.1-dev.1 - 开发中

- 自动保存失败时持续显示具体原因，并提供“重试保存”；当前输入保留在页面，成功保存或明确重新载入后清除提示。
- 未保存时将已有 PDF 标为上次预览；重新载入等待正在保存的请求结束，避免旧响应影响刚载入的状态。重试仍检查其他窗口或外部文件的修改冲突。

## v0.10.0 - 章节管理与填写体验优化

- 在“版式与图片”中调整当前简历的章节顺序、修改任意章节名称，并可恢复预设顺序；章节 ID、正文与图片保持不变。
- 补充章节名称也可在“技能与补充信息”表单中修改。PDF、Markdown 与备份文件名加入当前简历名称，方便区分同一人的不同版本。
- 联系方式类型切换时保留显示文字，未填完的地址作为本地草稿保存，不生成无效 PDF 链接；补全后重新生成可点击链接。
- 常用表单只更新改动的元数据字段，保留 YAML 注释、字段顺序、BOM / CRLF 换行和未修改的 Markdown 正文。

## v0.9.0 - 表单填写与首次使用优化

- 新增起步模板选择与填写导航，可从空白、奶龙校招或两页工作经验开始；已有资料直接进入编辑，从模板新建独立简历。
- 基本信息、教育、实习、工作、项目、技能与补充信息均提供表单；技能支持编辑、复制、排序和删除，保留 Markdown、加粗、链接与原段落顺序。
- 删除前完整备份，旧窗口与外部修改仍检查版本冲突；一页超量时可显式允许两页，字号保持原设置。
- 提供 Intel / Apple Silicon 原生 macOS 应用 ZIP，内置运行组件，支持双击打开、离线 PDF、重启与独立数据目录。
- 新增工作台模型 2、3、4 的显式转换 API 和 JSON 命令，返回章节映射与版式差异，保留完整元信息；结构化条目可省略日期。
- 使用正式 v0.8.0 ZIP 验证升级，覆盖多简历、图片、历史、回收站、新表单、单份与整库恢复、旧程序重新打开和新版重启；发布资料使用实际报告与文件摘要。

## v0.8.0 - 简历管理与跨平台启动

- 已有教育、实习、工作与自定义经历可编辑、复制、上下移动和删除，保留段落、编号列表、加粗与链接。
- 删除经历前保存完整备份，移除最后一条时同步处理空章节与排序；旧窗口或外部修改不会被覆盖。
- 简历回收站保留正文、图片和历史，恢复时可更名，至少保留一份在用简历。
- 整库 ZIP 包含全部简历、回收站、图片、历史和当前选择；恢复前保留原库 ZIP，失败或中断可回退。
- macOS Intel / Apple Silicon、Linux x64 / ARM64 启动包内置 Node、Chromium、字体和依赖，提供组件与环境检查。
- 设置界面按平台显示文件夹操作；现有数据位置与内容模型继续兼容。
- 使用已发布的 v0.7.0 包验证升级，逐文件核对原资料，并检查旧程序重新打开、回收站与重启保留。

macOS 包尚未签名、公证，Windows EXE 尚未签名；Linux 系统依赖与启动方式见[跨平台说明](portable.md)。

## v0.7.0 - 简历编辑与数据管理

- 照片裁剪支持拖动、缩放、旋转和重置，保存为 23:31 竖版 JPEG；调整已有照片前保留历史备份。
- 教育、实习与项目经历可通过表单添加，自动生成 Markdown 条目和日期字段，并合并到对应章节。
- 新增章节时同步已有排序配置；旧正文和其他简历保持不变。
- 数据与程序分开保存，支持查看、更换位置和打开已有简历库；旧版 `my-resume` 可自动识别或手动迁入。
- 迁移前保留整库副本，逐文件核对大小与 SHA-256；原资料、所有简历、图片与历史保留。
- 正式版本检查、安装包下载与 SHA-256 核验、独立目录准备、保存后切换及启动失败回退。
- 更新下载支持暂停、断线续传和重启后继续；准备完成的新版保存在本机，切换前重新核对程序文件。
- 小窗口中的“数据与更新”弹窗固定标题与关闭按钮，并显示下载进度和继续下载入口。
- 编辑器与命令行预览使用随包提供的离线 PDF 预览器，支持翻页、缩放、文本选择和正文链接；解决内置浏览器的原生 PDF 预览黑屏。

从 v0.6.0 升级时，首次启动会识别旧版 `my-resume`，迁移前保留整库副本。其他位置的资料可以通过“数据与更新 → 迁入旧版 my-resume”选择。版本发布规则见[维护说明](maintaining.md)。
