# Markdown 简历 · Windows 免安装版

1. 完整解压下载包，双击 **启动简历.exe**。
2. 在打开的页面填写基本信息和 Markdown 经历，右侧自动更新 PDF 预览。
3. 点击 **下载 PDF**。

照片、校徽和版式通过“版式与图片”设置。修改自动保存到 `my-resume/`，再次启动可继续编辑。切换起步模板前会备份当前内容；保留整个 `my-resume/` 文件夹即可备份自己的资料。

支持 Windows 10 / 11 x64。运行时、中文字体和 PDF 浏览器随包提供，解压后可断网使用。浏览器中的“退出”按钮会保存并关闭本地应用。更新版本时，将自己的 `my-resume/` 文件夹复制到新解压目录。
