# Markdown 简历 · Windows 免安装版

1. 完整解压下载包，双击 **启动简历.exe**。
2. 在打开的页面填写基本信息和 Markdown 经历，右侧自动更新 PDF 预览。
3. 点击 **下载 PDF**。

照片、校徽和版式通过“版式与图片”设置，照片可裁剪为 23:31。正文上方可通过表单添加教育、实习和项目经历。

“当前简历”支持新建、复制、重命名和切换，每份内容与图片独立保存，重启后继续上次选中的简历。

“备份与恢复”支持立即备份、导出当前简历的完整 ZIP、恢复历史版本和备份文件。ZIP 包含正文、版式和已引用的图片；恢复前会备份当前内容。有修改时每 5 分钟保留自动版本，切换与退出前也会保存。

数据默认保存在 `%LOCALAPPDATA%\TechResumeKit\data`，与程序文件夹分开。“数据与更新”显示完整路径，可以打开文件夹、迁移全部简历，或使用已有简历库。迁移前保留整库副本，完成后核对文件，原目录继续保留。

首次启动会识别程序旁的旧版 `my-resume`，也会检查同级旧版下载目录。找到唯一一份旧资料时自动迁入；其他位置或多份旧资料可在“数据与更新 → 迁入旧版 my-resume”中选择，目标需为空。

“检查正式版本”只检查正式 Release。下载包通过 SHA-256 校验后准备到独立目录，点击“保存并打开新版”才切换。切换前保存全部资料和整库副本；启动失败时自动尝试打开原程序，新版内也可以打开上一版本。原程序和副本保留，不自动删除。

支持 Windows 10 / 11 x64，解压后可断网使用。浏览器中的“退出”按钮会保存并关闭本地应用。
