# Markdown 简历 · Windows 免安装版

1. 完整解压下载包，双击 **启动简历.exe**。
2. 在打开的页面填写基本信息和 Markdown 经历，右侧自动更新 PDF 预览。
3. 点击 **下载 PDF**。

照片、校徽和版式通过“版式与图片”设置，修改自动保存到 `my-resume/`。

“当前简历”支持新建、复制、重命名和切换，每份内容与图片独立保存，重启后继续上次选中的简历。

“备份与恢复”支持立即备份、导出当前简历的完整 ZIP、恢复历史版本和备份文件。ZIP 包含正文、版式和已引用的图片；恢复前会备份当前内容。有修改时每 5 分钟保留自动版本，切换与退出前也会保存。

旧版资料留在原位置，自动成为第一份简历；新简历在 `my-resume/resumes/`，完整历史在 `my-resume/history/`。更新时复制整个 `my-resume/` 文件夹，保留所有简历与历史。

支持 Windows 10 / 11 x64，解压后可断网使用。浏览器中的“退出”按钮会保存并关闭本地应用。
